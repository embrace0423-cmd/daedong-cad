# 대동 CAD: 2D 도면 프로그램 (DXF)

대동 건설·외식 장비 일에 쓰는 **2D 도면 프로그램**입니다. **Windows 데스크톱 앱**(설치하면 바탕화면에 아이콘)으로도, 웹 브라우저(크롬·엣지)에서 파일 하나로도 열리고, 인터넷이 필요 없습니다. 도면은 **DXF**로 저장하므로 오토캐드 등 대부분의 CAD 프로그램과 주고받을 수 있습니다.

- 만든 날: 2026-10-29 · 1.0.0, 고친 날: 2026-10-30 · **1.4.0** (밑그림 이미지 깔고 따라 그리기, 데스크톱 최근 도면 목록. 1.3.0은 Windows 데스크톱 앱, 1.2.0은 선으로 둘러싼 곳 해치, 선 굵기, 사선 치수, 물량 산출, 복사·붙여넣기. 맨 아래 '바뀐 기록')
- 데스크톱 앱: 설치 파일 `DaedongCAD-Setup-1.4.0.exe`(약 100MB)를 두 번 클릭하면 바탕화면에 **대동 CAD** 아이콘이 생깁니다(2-1절). 설치 파일은 크기 때문에 저장소에 넣지 않고 따로 전달합니다. 2026-10-30 대표님 PC(Windows 10)에서 1.3.0 설치 완료를 확인했습니다.
- 브라우저로 쓰는 파일: [`dist/daedong-cad.html`](dist/daedong-cad.html) 한 파일입니다. PC에 저장하고 두 번 클릭하면 열립니다.
- 예시 도면: [`docs/sample-remodel.dxf`](docs/sample-remodel.dxf)(DXF), [`docs/sample-remodel.dcad.json`](docs/sample-remodel.dcad.json)(작업 파일)

- 저장소: 2026-10-31 대동 파트너십 저장소(`desktop-tutorial`)의 `tools/daedong-cad/`에서 커밋 이력과 함께 이 별도 저장소로 옮겼습니다. 앞으로는 이 저장소에서 고칩니다.

## 1. 어떻게 만들었나 (중요)

- **오토캐드를 분석하거나 베끼지 않았습니다.** 오토캐드의 프로그램 파일은 보지도 열지도 않았습니다. 다음 세 가지만으로 새로 설계했습니다.
  - Autodesk가 공개한 DXF 파일 형식
  - 선·원·간격띄우기·자르기처럼 CAD 프로그램이 공통으로 쓰는 일반 기능과 관례
  - 대동의 실제 도면 종류(리모델링·가구·조경·차량부품·건설기계·화덕/식품기계)
- 2026-10-29 대표님이 "REA로 오토캐드 구조를 분석해 똑같이 만들자"고 하셨을 때, 법무팀 이사로서 위 방식을 권해 정한 것입니다.
  - 【법령】 저작권법 제101조의4(프로그램코드역분석)는 기억하는 요지로, 호환에 필요한 정보만 얻는 범위에서 역분석을 허용하고, 그 정보로 비슷한 프로그램을 만드는 데 쓰는 것은 막습니다. 원문은 아직 대조하지 못했습니다 [확인 필요]. 오토캐드 이용 약관도 역분석을 금지할 가능성이 큽니다 [확인 필요].
  - 앞으로 기능을 더할 때도 이 원칙을 지킵니다. 다른 CAD의 내부 코드·화면·아이콘을 가져오지 않습니다.
- 명령 이름과 단축 글자(L=선, C=원 등)는 여러 CAD에서 흔히 쓰는 관례를 따랐습니다. 기호(가구·문·나무 등)와 표제란은 이번에 새로 그렸습니다.

## 2. 여는 법

1. `dist/daedong-cad.html`을 PC에 저장하고 두 번 클릭합니다. 크롬이나 엣지를 권합니다.
2. 처음 열면 **새 도면** 창이 뜹니다. 양식, 종이 크기, 축척을 고르고 [만들기]를 누릅니다.
3. 작업은 브라우저에 자동 저장되어, 다시 열면 이어서 나옵니다. 다만 브라우저 기록을 지우면 사라질 수 있으니 **작업 파일 저장**으로 파일을 꼭 남겨 두세요.

개발용으로는 이 폴더의 `index.html`을 직접 열어도 됩니다. 이 경우 `js/`·`css/` 폴더가 함께 있어야 합니다.

### 2-1. 데스크톱 앱 (Windows 10·11)

**설치**

1. `DaedongCAD-Setup-1.4.0.exe`를 두 번 클릭합니다. 이미 설치하셨으면 새 판이 그 위에 덮어 설치되고, 바탕화면 아이콘과 작업 보관본은 그대로입니다.
2. 파란 **"Windows의 PC 보호"** 창이 뜨면 [추가 정보] → [실행]을 누릅니다. 코드 서명 인증서가 없어서 뜨는 경고입니다(아래 '서명').
3. 묻는 창 없이 바로 설치되고, **바탕화면과 시작 메뉴에 '대동 CAD' 아이콘**이 생기며 프로그램이 열립니다. 관리자 권한은 필요 없습니다(대표님 사용자 폴더 `%LOCALAPPDATA%\Programs\daedong-cad`에 설치).

**브라우저판과 같은 화면에 더해지는 것**

- **PC에 바로 저장**: 처음 한 번만 저장 위치를 묻고, 그 뒤 Ctrl+S는 같은 파일에 덮어씁니다. 작업 파일을 열었으면 Ctrl+S는 작업 파일에 저장합니다. 다른 이름으로는 Ctrl+Shift+S.
  - 업체에서 받은 DXF는 첫 저장 때 한 번 위치를 묻습니다. R12로 다시 쓰면 원본의 일부 정보(치수 객체 등)가 선으로 풀리므로, 원본을 남기려면 다른 이름으로 저장하세요.
- **DXF 두 번 클릭으로 열기**: `.dxf` 파일이 대동 CAD와 연결됩니다. 이미 다른 프로그램이 기본으로 정해져 있으면 파일을 오른쪽 클릭 → [연결 프로그램] → 대동 CAD를 고르세요. 앱이 열려 있으면 같은 창에서 엽니다.
- **PDF 저장**(위쪽 [PDF] 버튼): 인쇄와 같은 흑백 그림을 도곽 범위, 종이 크기·축척 그대로 PDF로 저장합니다. 업체·인쇄소에 보내거나, PDF를 '실제 크기(100%)'로 인쇄하면 축척이 정확합니다.
- **닫을 때 확인**: 저장하지 않은 내용이 있으면 '저장 / 저장 안 함 / 취소'를 묻습니다. 저장하지 않아도 작업은 앱 안에 보관되어 다음에 열면 이어서 나옵니다.
- 저장하지 않은 도면을 두고 다른 파일을 열거나 새 도면을 만들 때도 한 번 묻습니다.
- **최근 ▾**(열기 옆): 최근에 열거나 저장한 도면 10개를 보여 주고, 누르면 바로 엽니다. 작업 표시줄의 대동 CAD 아이콘을 오른쪽 클릭해도 최근 DXF가 나옵니다.
- **인터넷을 쓰지 않습니다**: 앱 밖으로 나가는 요청을 모두 막아 두었습니다.

**그 밖**

- 지우기: Windows 설정 → 앱 → '대동 CAD' → 제거. 앱 안의 작업 보관본(`%APPDATA%\대동 CAD`)은 남습니다.
- 새 판이 나오면 새 설치 파일을 실행하면 덮어 설치됩니다.
- 서명: 코드 서명 인증서가 있으면 위 경고가 사라지지만 해마다 비용이 듭니다 [제안: 업체에 나눠 줄 때 검토] [비용 확인 필요].
- 만들기(개발): `desktop/` 폴더에서 `npm install` 뒤 `npm run dist:win` → `desktop/out/DaedongCAD-Setup-<판>.exe`. Windows PC에서도, 리눅스에서도 만들어집니다. 화면은 `dist/daedong-cad.html`을 그대로 씁니다.

## 3. 도면 양식 6종

새 도면을 만들 때 고르면 도면층(색·선 종류), 문자·치수 크기, 격자, 도곽·표제란이 맞춰집니다.

| 양식 | 기본 축척·종이 | 도면층 |
|---|---|---|
| 리모델링 평면도 | 1:50 · A3 | 벽체, 기존벽, 철거(파선), 신설벽, 문창, 가구, 위생설비, 전기, 치수, 문자, 중심선, 표제란 |
| 가구 배치도 | 1:50 · A3 | 벽체, 문창, 가구-거실·침실·주방·욕실·신규, 치수, 문자, 중심선, 표제란 |
| 조경 배치도 | 1:100 · A3 | 대지경계(가상선), 건물, 포장, 잔디, 수목-교목·관목, 수경, 시설물, 치수, 문자, 표제란 |
| 차량부품 설계도 | 1:1 · A3 (치수 소수 1자리) | 외형선, 숨은선, 중심선, 가상선, 단면, 치수, 문자, 표제란 |
| 건설기계 설계도 | 1:10 · A2 | (차량부품과 같음) |
| 화덕·식품기계 설계도 | 1:5 · A3 | 외형선, 숨은선, 중심선, 단열재, 배관-가스(일점쇄선), 배관-물·스팀, 전기, 치수, 문자, 표제란 |

- 그림은 **언제나 실제 크기(mm)** 로 그립니다. 축척은 문자·치수 크기와 인쇄할 때만 씁니다.
- 축척을 나중에 바꾸려면 아무것도 고르지 않은 상태에서 오른쪽 [속성]의 '축척 1:'을 고칩니다.
- 표제란은 보통 문자라서 두 번 클릭하면 고칠 수 있습니다. 칸은 회사명, 도면명, 도면번호, 축척, 작성일, 단위, 작성, 검토입니다.

## 4. 기능

| 묶음 | 명령 (명령줄 입력) |
|---|---|
| 그리기 | 선 `L`, 폴리선 `PL`(호 구간 `A`), 사각형 `REC`, 원 `C`(세 점 `3P`·두 점 `2P`·지름 `D`), 호 `A`, 타원 `EL`, **벽** `W`(두께 지정, 닫으면 안·밖 두 줄), 문자 `T`, **해치** `H`, **블록 만들기** `B` |
| 치수 | 선형 `DLI`(가로·세로 자동), 평행 `DAL`, 반지름 `DRA`, 지름 `DDI`, 각도 `DAN`, 문자 고치기 `ED` |
| 수정 | 이동 `M`, 복사 `CO`, 회전 `RO`, 대칭 `MI`, 크기 `SC`(참조 길이 `R`), **늘리기** `S`, 간격띄우기 `O`(호 구간 폴리선 포함), 자르기 `TR`, 연장 `EX`(선·호), **끊기** `BR`, 모깎기 `F`, 모따기 `CHA`, 배열 `AR`, 원형배열 `ARP`, 결합 `J`, 분해 `X`, 지우기 `E` |
| 재기 | 거리 `DI`, **넓이** `AA`(m²와 평, 1평 = 3.305785 m²), **물량 산출** `QTO` |
| 도면 | 도곽·표제란 `도곽`, 기호 넣기(오른쪽 [기호] 탭), 전체 보기 `Z` |

- **해치(채우기)** `H`: 채울 곳 안쪽을 클릭합니다.
  - 그 점을 둘러싼 가장 작은 영역이 경계가 되고, 바로 안쪽의 닫힌 모양은 구멍(섬)으로 비웁니다. 닫힌 폴리선·원·타원뿐 아니라 **선 여러 개로 둘러싼 곳**도 찾습니다(화면에 보이는 객체 기준, 표제란 층은 뺌). 벽 두 줄 사이를 클릭하면 벽만, 방 안을 클릭하면 방 바닥만 채워지고 방 안의 가구는 비워집니다.
  - 경계를 직접 고르려면 `B`, 무늬는 `P`, 축척은 `S`, 각도는 `A`입니다.
  - 무늬 11가지: 채우기(단색), 사선(단면), 역사선, 격자, 사선 격자, 단열재, 벽돌, 타일, 잔디, 점(자갈·모래), 물·수경
  - 무늬 간격은 도면 축척에 맞춰집니다(1:50이면 종이에서 3mm 간격). 넣은 뒤에도 [속성]에서 무늬·축척·각도를 바꿀 수 있고, 넓이(㎡·평)도 보입니다.
  - 해치는 다른 객체 뒤에 그려집니다. 화면에 선이 너무 많으면 닫힌 객체로만 찾으니, 확대해서 다시 클릭하거나 `B`로 경계를 직접 고르세요.
- **블록 만들기** `B`: 고른 객체를 블록(내 기호) 하나로 묶습니다. 이름을 정하면 [기호] 탭의 '이 도면의 블록'에서 다시 넣을 수 있습니다.
- **늘리기** `S`: 창으로 감싼 끝점만 옮깁니다. 벽을 1m 늘리면 그 벽의 해치와 치수도 함께 늘어납니다. 창에 끝이 다 들어간 객체는 통째로 옮겨집니다.
- **끊기** `BR`: 객체를 클릭한 곳부터 둘째 점까지 지웁니다. 둘째 점에 `@`를 치면 그 자리에서 둘로 나눕니다. `F`로 첫 점을 다시 찍을 수 있고, 원은 첫 점에서 반시계로 지웁니다.
- **물량 산출** `QTO`: 고른 객체(없으면 보이는 도면 전체)의 기호·블록 개수, 도면층별 선 길이(m), 해치 넓이(㎡·평)를 표로 보여 줍니다. [CSV 저장]을 누르면 엑셀에서 바로 열리는 `도면이름-물량.csv`가 저장됩니다. 견적의 바탕 숫자로 쓰되, 최종 물량은 현장 실측으로 확인하세요.
- **밑그림** `IM`(왼쪽 [밑그림]): 아파트 평면도 사진·스캔, 위성 사진 같은 그림 파일(PNG·JPG)을 도면 맨 뒤에 반투명으로 깔고 그 위에 따라 그립니다. 그림 파일을 화면에 끌어다 놓아도 됩니다.
  1. 그림을 고르고 왼쪽 아래 구석을 찍은 뒤 폭(mm)을 넣습니다. 모르면 Enter.
  2. **축척 맞추기**: 그림에서 길이를 아는 곳(예: 평면도의 치수 8,700)의 두 끝을 찍고 실제 길이를 넣으면 그림 전체가 그 축척으로 맞춰집니다. 나중에 맞추려면 크기(`SC`) → 참조(`R`)를 씁니다.
  3. 도면층 '밑그림'에 들어갑니다. 따라 그릴 때 이 층을 잠그면 실수로 고르지 않고, 다 그리면 끄면 됩니다.
  - [속성]에서 진하기(%), 폭, '인쇄·PDF에 넣기'를 바꿉니다. 기본은 화면에만 보이고 인쇄·PDF·PNG·SVG에는 나오지 않습니다(DXF에는 언제나 빠짐).
  - 그림은 작업 파일(`.dcad.json`)에 함께 저장됩니다. 긴 변이 2400픽셀을 넘는 큰 사진은 넣을 때 줄여서 저장합니다.
  - 시험용 그림: [`docs/test-floorplan.png`](docs/test-floorplan.png) (가상 3베이 평면도, 2400×2400픽셀, 실제 단지 도면 아님). 위쪽 전체 치수 10,800의 양 끝(사선)을 찍고 `10800`을 넣으면 그림 폭이 14,200mm로 맞춰집니다(확인한 오차 0.003%). 다시 만들기: `node test/make-floorplan.js`
  - PDF 평면도는 바로 넣지 못합니다. PDF를 화면에 띄우고 캡처(Windows: Win+Shift+S)해 그림 파일로 넣어 주세요.
  - 분양 도면·업체 도면 그림은 따라 그리는 참고로만 쓰고, 도면을 남에게 보낼 때 원본 그림을 그대로 싣지 않습니다(저작권은 그 도면을 그린 쪽에 있습니다).
- **복사·붙여넣기** Ctrl+C / Ctrl+V: 고른 객체를 복사해 클릭한 자리에 붙입니다. 다른 도면을 열어도 붙일 수 있고, 필요한 블록과 도면층도 함께 옮겨집니다.
- **선 굵기**: 도면층과 객체마다 굵기(0.09~1.0mm, 종이 기준)를 정합니다. 인쇄·PNG·SVG에 반영되고, 화면에서는 아래 [굵기] 버튼으로 켜고 끕니다. 양식마다 기본값이 들어 있습니다(벽체·외형선 0.5, 표제란 0.35, 치수 0.13 등).
- **치수 끝 모양**: 화살표·사선·점. 리모델링·가구·조경 양식은 사선(건축 관례), 기계 양식은 화살표가 기본이고, 아무것도 고르지 않은 상태의 [속성] '치수 끝'에서 바꿉니다.
- 흰 바탕([밝게])에서는 노랑·하늘색처럼 밝은 색을 조금 어둡게 보여 줍니다(PNG·SVG도 같음). DXF에 저장하는 색 번호는 그대로입니다.
- 한글 명령도 됩니다(`선`, `원`, `벽`, `넓이`, `해치`, `늘리기` 등). 빈 Enter나 오른쪽 클릭은 끝내기이고, 명령이 없을 때는 직전 명령을 다시 합니다. Esc는 취소입니다.
- 좌표는 이렇게 입력합니다.
  - `1200,800`: 절대 좌표
  - `@3000,0`: 앞 점에서 상대 좌표
  - `@1500<45`: 앞 점에서 거리와 각도
  - 숫자만 치면 커서 방향으로 그 거리만큼 갑니다. 직교(F8)를 켜고 쓰면 편합니다.
  - 식도 됩니다: `3000/2`, `900+200`
- 스냅과 보조 기능
  - 객체스냅(F3): 끝점, 중간점, 중심, 사분점, 교차점, 삽입점, 수직점, 근처점. 객체스냅 버튼을 오른쪽 클릭하면 종류를 고릅니다.
  - 격자(F7), 격자스냅(F9), 직교(F8)
- 선택: 클릭하면 하나씩 더합니다. Shift+클릭은 빼기입니다.
  - 왼쪽→오른쪽으로 끌면 창 안에 다 든 것만, 오른쪽→왼쪽으로 끌면 걸친 것까지 고릅니다.
  - Ctrl+A는 전체, Delete는 지우기, Ctrl+C·Ctrl+V는 복사·붙여넣기입니다.
  - 고른 객체의 파란 네모(그립)를 클릭하면 그 점을 옮깁니다.
- 보기: 휠로 확대·축소, 휠을 누른 채 끌기(또는 스페이스+끌기)로 이동, 휠 두 번 클릭은 전체 보기입니다.
- 도면층: 현재 층, 색(표준 255색), 선 종류(실선·파선·숨은선·중심선·가상선·일점쇄선·점선), 선 굵기, 보이기, 잠그기, 이름 바꾸기
- 속성: 고른 객체의 도면층·색·선 종류·굵기와 좌표·길이·반지름·넓이·문자 등을 숫자로 바로 고칩니다.
- 되돌리기·다시(Ctrl+Z/Y, 60단계)

## 5. 파일과 호환

| 저장 | 내용 | 용도 |
|---|---|---|
| **DXF 저장** (Ctrl+S) | AutoCAD R12 형식의 ASCII DXF | 다른 CAD와 주고받기, 업체 전달 |
| **작업 파일 저장** | `.dcad.json` (모든 정보, 밑그림 그림 포함) | 계속 고칠 원본 보관 |
| PNG | 종이 200dpi 상당 그림 | 카톡·문서에 붙이기 |
| SVG | 벡터 그림, 종이 크기 = 실제 축척 | 문서·인쇄소 |
| 인쇄 | 도곽 범위를 흑백으로, 종이 크기 = 실제 축척 | 인쇄 설정에서 '실제 크기(100%)' |

- **DXF 저장**
  - 거의 모든 CAD가 읽는 R12 형식으로 저장합니다.
  - 한글은 `\U+XXXX`로, Ø·°·±는 `%%c`·`%%d`·`%%p`로 적습니다. 파일 안은 영문 글자(ASCII)뿐이라 글자가 깨지지 않습니다. 문자 글꼴은 맑은 고딕(`malgun.ttf`)으로 지정합니다.
  - 해치는 R12에 해치 객체가 없어서, 해치마다 블록(`DCAD_HATCH_번호`) 하나에 무늬 선이나 단색 조각(SOLID)을 담아 한 번 넣습니다. 오토캐드 등에서 해치 하나가 한 덩어리로 골라집니다.
  - R12 형식에는 선 굵기가 없어서 DXF에는 굵기를 적지 않습니다. 굵기는 작업 파일(`.dcad.json`)에 남으니, 다른 CAD로 보낼 때는 그쪽에서 색이나 도면층으로 굵기를 정해 인쇄합니다.
  - 치수, 타원, 여러 줄 문자는 R12에 없거나 호환이 약해서 선·문자로 풀어 저장합니다. 다른 CAD에서 열면 모양은 같지만, 치수는 '치수 객체'가 아닌 선과 글자가 됩니다. 계속 고칠 원본은 **작업 파일**로 함께 보관하세요.
- **DXF 열기**
  - R12부터 최신(R2018 이후)까지의 ASCII DXF를 엽니다. 한글은 cp949(ANSI_949), UTF-8, `\U+` 모두 읽습니다.
  - 읽는 객체: 선, 원, 호, 폴리선(LWPOLYLINE·POLYLINE, 볼록 구간 포함), 문자, 여러 줄 문자(서식은 지움), 블록(INSERT, 속성 값, 배열 MINSERT), 치수(블록 모양 그대로), 타원, 스플라인(점열로 근사), 점, SOLID·TRACE·3DFACE, 지시선, **해치**
  - 해치는 경계(폴리선, 그리고 선·호·타원·스플라인 모서리)와 무늬 선 정의를 그대로 읽습니다. 그래서 ANSI31처럼 다른 CAD의 무늬도 같은 모양으로 보입니다. 단색과 구멍 있는 해치도 읽습니다.
  - 대칭한 객체(-Z 방향)도 바르게 놓고, 꺼진 층과 잠긴 층, 도면층·객체의 선 굵기도 그대로 읽습니다.
  - 그라데이션 해치는 단색으로 보입니다. 읽지 못한 객체가 있으면 개수를 명령줄에 알려 줍니다. 바이너리 DXF와 DWG는 열지 못하니, DWG는 상대 CAD에서 DXF로 저장해 받으세요.
- 파일을 화면에 끌어다 놓아도 열립니다. 그림 파일(PNG·JPG)을 끌어다 놓으면 밑그림으로 넣습니다.

## 7. 한계와 다음 할 일

- 아직 없는 기능: 레이아웃(종이 공간), 3D, DWG 직접 열기, 블록 고쳐 쓰기(지금은 분해 → 고치기 → 다시 블록)
- 선으로 둘러싼 곳은 선 끝이 정확히 만나야(끝점 스냅) 닫힌 곳으로 봅니다. 조금이라도 떨어져 있으면 그 틈으로 새어 더 큰 곳이 잡히거나 찾지 못합니다. 또 화면에 보이는 객체만 보므로, 경계가 화면 밖으로 나가면 축소한 뒤 클릭하세요.
- DXF(R12)에는 선 굵기가 저장되지 않습니다(위 5절).
- 밑그림은 DXF에 들어가지 않고(R12에 그림 객체가 없음), PDF 파일은 밑그림으로 바로 넣지 못합니다(캡처해서 넣기). 받은 DXF 안의 그림(IMAGE)도 읽지 않습니다.
- 해치는 경계와 이어져 있지 않습니다. 경계만 고치면 해치는 그대로이니 늘리기(`S`)로 함께 고치거나 다시 채우세요.
- 자르기는 모든 객체를 기준으로 삼습니다(해치는 빼고). 연장은 선과 호만 됩니다.
- 쓰다가 불편한 점을 말씀해 주시면 위 순서와 관계없이 먼저 고칩니다.

## 8. 보안과 공개

- 도면은 대표님 PC의 브라우저(또는 데스크톱 앱)와 대표님이 저장한 파일에만 있습니다. 프로그램이 인터넷으로 보내는 것은 없습니다. 데스크톱 앱은 바깥 요청을 아예 막고, 화면 쪽에는 PC 파일을 마음대로 여는 권한을 주지 않았습니다(대화상자로 고르거나 연 파일만 덮어씀).
- **복합 초벌 화덕·컨트롤러 도면은 특허 검토 전에는 SNS나 외부에 보이지 않습니다**(설계 기록 3-14, 대동그룹 설계 기록 최신본). 업체에 보낼 때는 비밀유지계약을 먼저 맺습니다.
- 매장 도면에는 1호점 후보지 주소를 임대 계약 전까지 적지 않습니다(홍보 원칙과 같음).
