# 설치기 오류 코드

0은 해당 작업 성공이다. 다음 코드는 사용자 대상 폴더에 진단 파일을 쓰지 않고 실패 이유를 구분한다.

| 코드 | 이유 |
|---|---|
| 10 | 드라이브 루트에 설치하거나 제거할 수 없습니다. |
| 11 | 로컬 드라이브의 절대 경로를 선택하세요. |
| 12 | 연결된 폴더(정션/심볼릭 링크)에는 설치하거나 제거하지 않습니다. |
| 13 | 대상 경로의 속성을 확인할 수 없습니다. 기존 파일을 보존하고 중단합니다. |
| 14 | 이 설치본의 소유 경로를 확인할 수 없습니다. 기존 파일을 보존하고 중단합니다. |
| 15 | 설치 표식의 버전이 손상되었습니다. 기존 파일을 보존하고 중단합니다. |
| 16 | 대동 CAD가 실행 중이거나 파일에 접근할 수 없습니다. 해당 설치본을 직접 종료한 뒤 다시 시도하세요. |
| 17 | 제품 파일이 사용 중이거나 변경 권한이 없습니다. 기존 파일을 보존하고 중단합니다. |
| 18 | 이 설치본은 Windows x64용입니다. |
| 19 | 일반 설치와 격리 시험 설치를 같은 경로에서 바꾸지 않습니다. |
| 20 | 더 새로운 버전이 설치되어 있습니다. 이전 버전으로 덮어쓰지 않습니다. |
| 21 | 기존 제거기를 확인할 수 없습니다. 설치본을 보존하고 중단합니다. |
| 22 | 선택한 폴더가 비어 있지 않고 이 제품의 설치 표식도 없습니다. 다른 빈 폴더를 선택하세요. |
| 23 | 이 정식 제품은 다른 경로에 등록되어 있습니다. 그 설치본을 보존하고 중단합니다. |
| 24 | 이전 설치의 준비/보존 폴더가 남아 있습니다. 파일을 확인하여 별도 보관한 뒤 다시 시도하세요. |
| 25 | 설치 교체에 실패해 기존 앱/제거기/설치 정보를 복원했습니다. 준비 폴더는 보존했습니다. |
| 26 | 설치 교체와 일부 복원에 실패했습니다. app.previous 및 .previous 파일을 보존했으니 복원 안내를 확인하세요. |
| 27 | 설치 파일 쓰기에 실패했습니다. 기존 앱은 바꾸지 않았으며 준비 폴더를 보존했습니다. |
| 28 | 앱은 설치됐지만 제거 정보 등록에 실패했습니다. 기존 앱 보존 폴더를 유지했습니다. |
| 29 | 일부 제품 파일을 제거하지 못했습니다. 남은 파일과 설치 정보를 보존했습니다. |

경로 오류 수집은 [NSIS System 공식 문서](https://nsis.sourceforge.io/Docs/System/System.html)의 `?e` 옵션으로 해당 Win32 호출 직후 얻은 오류값을 사용한다. 별도 GetLastError 호출 사이에 오류 값이 바뀌는 것을 방지한다.
