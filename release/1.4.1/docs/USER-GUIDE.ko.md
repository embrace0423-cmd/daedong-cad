# 대동 CAD 1.4.1 설치·저장·복원 안내

Windows x64용 안내다. 설치기의 이름은 `DaedongCAD-Setup-1.4.1.exe`다. 앱 실행에는 별도 Node/Python 설치가 필요하지 않는다. 분할 운반 패키지를 받은 경우에는 먼저 그 패키지의 복원 안내와 체크섬으로 정상 설치 파일을 복원한다. 운반 조각이나 복원 도구가 앱을 자동 실행하는 것은 아니다.

이 문서 자체는 설치·실행 시험 완료의 증거가 아니다. 제공된 설치기의 해시와 같은 판본의 검증 결과·종합검토 접수증을 확인한다.

이 안내의 제품 파일 경로는 제품 ZIP을 푼 최상위 폴더 기준이다. 현재 설치기의 재현성 기록은 `build-evidence/reproducible-builds-v2.json`이며 원작업의 `verification/reproducible-builds-v2.json`을 제품 ZIP에 복사한 것이다. 실제 UI·기능 시험과 최종 판정은 별도 검증자료·접수증에서 확인한다.

## 설치와 시작

1. 기존 대동 CAD에서 작업 중이라면 작업 파일을 저장하고 별도 백업한다. 이 설치기는 기존 1.4.0을 덮어쓰거나 그 앱을 강제로 종료하지 않는다.
2. 제공된 체크섬과 설치 파일이 같은지 확인한 후 설치기를 실행한다. 현재 사용자 권한으로 설치하며 관리자 권한 확대나 재부팅을 요구하는 방식으로 설계되지 않았다. 실행 파일과 설치기는 미서명이므로 시스템 또는 조직이 실행을 막으면 해당 승인 절차를 따른다. 보호 기능을 끄거나 우회하지 않는다.
3. 기본 경로 `%LOCALAPPDATA%\Programs\DaedongCAD-Release`를 사용한다. 다른 경로는 비어 있는 로컬 폴더를 선택한다. 기존 사용자 자료 폴더나 운영 설치 폴더를 설치 대상으로 지정하지 않는다.
4. 설치 후 `%LOCALAPPDATA%\Programs\DaedongCAD-Release\app\DaedongCAD.exe`를 실행한다. 다른 설치 경로를 선택했다면 그 아래 `app\DaedongCAD.exe`를 사용한다. 이 버전은 바로가기를 만들거나 설치 직후 앱을 자동 실행하지 않는다.
5. 창과 상단에 1.4.1이 표시되는지 확인한다. 기존 파일은 먼저 사본으로 열어 실제 단위와 도면 내용을 확인한다.

일반 설치의 Windows 앱 목록 이름은 **대동 CAD (정식)**이다. 기존 1.4.0의 설치·제거 항목과는 별개다. 개발·검증용 `/TESTMODE`는 레지스트리 등록을 생략하는 기능이며 일반 사용자가 선택할 필요는 없다.

## 기존 1.4.0 자료와 새 프로필

새 버전의 사용자 프로필은 `%APPDATA%\DaedongCAD-Release`다. 기존 1.4.0의 최근 파일·설정·자동복구 자료를 자동으로 옮기지 않는다. 필요할 때 기존 앱에서 정식 작업 파일로 저장하고 그 사본을 새 앱에서 열어 확인한다. 두 버전의 프로필 파일이나 설치 파일 일부를 임의로 섞지 않는다.

프로필에는 최근 파일·설정·브라우저 복구 자료가 포함될 수 있다. 프로필을 백업하려면 해당 앱을 정상 종료한 후 폴더 전체를 별도 사본으로 보존한다. 기존 프로필 위에 다른 프로필을 덮어쓰는 복원은 이 안내의 자동 절차가 아니다.

## 작업 저장과 DXF 내보내기

- **작업 파일 저장 / Ctrl+S:** 편집 가능한 `.dcad.json`에 저장한다. 처음 저장하거나 다른 이름으로 저장할 때는 파일 경로를 선택한다. 작업 파일에는 도면 정보와 밑그림 이미지가 함께 들어갈 수 있다.
- **DXF 내보내기:** 외부 CAD 교환용 R12 파일을 별도로 만든다. 이것만으로 작업 파일이 저장되거나 미저장 표시가 없어지는 것은 아니다.
- **단위:** 내부 기준은 mm다. 인치 입력은 확인 후 25.4배로 변환한다. 단위 미상 파일은 원본을 확인한 뒤 선택하며, cm/m 등 다른 명시 단위는 원본 프로그램에서 mm나 인치로 다시 저장하여 가져온다. 내보낸 R12를 외부 프로그램에서 열 때도 단위를 확인한다.
- **변환 손실:** DXF에서 밑그림은 제외되고 치수·여러 줄 문자·해치가 변환되며 타원은 근사된다. 경고에 나온 제외·변환 개수를 확인하고 원래 편집 정보를 가진 작업 파일을 함께 보관한다.

작업 파일 전체 한도는 이미지 포함 **64MiB(67,108,864바이트)**다. 초과하면 열기·저장을 거부한다. 자동복구 저장 공간은 이 한도와 다르며 더 작은 자료에서도 부족할 수 있다. 자동 보관 오류가 보이면 정식 작업 파일 저장으로 확인한다.

## 저장 실패와 이전 파일 복원

파일이 사용 중이거나 공간·권한이 부족하고, 현재 파일이 외부에서 바뀌었거나 저장 기준을 확인할 수 없으면 저장이 실패할 수 있다. 오류 안내와 미저장 표시를 확인하고 앱을 성급히 닫지 않는다. 저장 대상 앱의 사용을 직접 끝내거나, 충분한 공간과 권한이 있는 **새 파일 이름**으로 저장한 뒤 다시 열어 확인한다. 외부에서 바뀐 파일을 강제로 덮어쓰지 않는다.

기존 파일을 바꿀 때 같은 폴더에 `원래파일명.dcad-backup-...` 형태의 이전 바이트 백업이 남을 수 있다. 복원이 필요하면 원래 파일과 백업을 모두 보관하고, 확인할 백업을 **새 `.dcad.json` 이름으로 복사**해 연다. 정상 내용임을 확인하기 전 원래 파일 위에 덮어쓰지 않는다. 백업 파일은 누적될 수 있으므로 공간을 확인하되 중요한 이전본을 먼저 별도 보관한다.

`.dcad-tmp-...` 또는 `.dcad-backup-incomplete-...`가 포함된 숨김 파일은 완료된 백업과 다르다. 강제 종료 후 남은 조각을 정상 도면이라고 가정하거나 원래 파일에 덮어쓰지 않는다. 원래 파일·완성된 백업·미완성 조각을 구분하여 보존하고 확인한다. 프로그램의 마지막 검사 이후 다른 프로그램이 동시에 쓰는 모든 경쟁 상황을 완전히 막는 것은 아니다.

## 복구 보관본

복구된 도면은 **복구됨 · 작업 저장 필요** 상태로 열린다. 필요한 내용을 정식 작업 파일로 저장해야 저장이 완료된다. ‘복구 보관본’에서는 최근 세 세대 중 선택할 수 있다. 손상된 복구본을 거부하면 현재 도면은 유지되므로 다른 세대를 확인할 수 있다.

종료 창의 ‘저장 안 함’은 정식 작업 파일로 저장하지 않는 선택이다. 최신 복구 보관이 확인되면 닫고, 복구 보관에 실패하면 창을 닫지 않는다. 자동복구는 정식 작업 파일과 독립 백업을 대체하지 않으며 실제 정전·강제 종료 상황의 모든 데이터를 보장하지 않는다.

## 같은 정식 제품의 재설치와 제거

재설치 전 해당 설치본의 작업을 저장하고 앱을 정상 종료한다. **현재 실제 시험은 동일 1.4.1 → 1.4.1 재설치에 한정된다.** 향후 다른 판본으로 업그레이드할 때는 그 판본의 검증된 설치·이전 안내를 확인한다. 사용 중인 파일이나 이전 설치의 준비/보존 파일이 있으면 설치기가 중단하므로 해당 내용을 확인한다. 일반 설치와 시험 설치의 모드를 바꾸거나 더 오래된 버전으로 덮어쓰지는 않는다. 기존 1.4.0 운영 설치와 그 자료는 새 정식 설치 경로로 자동 이전되지 않는다.

제거는 Windows 앱 목록의 **대동 CAD (정식)** 또는 설치 폴더의 `Uninstall DaedongCAD.exe`를 사용한다. 기본 경로는 `%LOCALAPPDATA%\Programs\DaedongCAD-Release\Uninstall DaedongCAD.exe`다. 제거 전 작업을 저장하고 해당 설치본을 정상 종료한다. 제거기는 제품 소유 파일과 해당 제거정보만 정리하며 사용자 프로필·도면·알 수 없는 추가 파일은 남긴다. 따라서 사용자 파일이 있으면 설치 폴더가 남을 수 있다. 일부 파일을 제거하지 못했다는 오류가 나오면 제거 완료로 간주하지 않는다.

설치 교체 실패 후 `app.new`, `app.previous`, `.uninstall.new.exe`, `.uninstall.previous.exe`, `.marker.new`, `.marker.previous`가 남을 수 있다. 오류 메시지와 이 파일들을 보존한다. 앱·제거기·설치 표식을 하나의 같은 판본으로 복원해야 하므로 일부만 임의로 섞거나 남은 파일을 무조건 삭제하지 않는다. 소유 표식과 백업 해시를 대조하는 세부 절차는 `packaging/BUILD.md`의 실패 시 복원 안내를 따른다.

## 검증 범위와 자동 캡처 상태

실제 시험, 오류 주입, 시험 프로세스 강제 종료, 미시험 항목은 배포판의 검증 기록에서 구분한다. 실제 시스템 디스크 포화·PC 전원 차단·모든 다른 PC/파일시스템·모든 CAD 호환성을 시험했다고 보장하지 않는다.

자동 캡처 오류는 대표님 지시로 이 데스크톱에서 미해결·해결 불가 처리하고 추가 수리·반복 시도를 종료했다. 기술적으로 영구 불가능하다는 증명이나 해결 성공이 아니다. 부모 대화는 AI 관제 상태 등록 완료를 확인했다고 전달했다. 이 상태는 제품 설치·저장 검증과 구분하며 화면 캡처 성공을 주장하지 않는다.

제품 ZIP의 `docs/CAPTURE-DISPOSITION.md`는 이 종료 상태와 원작업 근거 위치를 설명한다. 제품 ZIP에 원래 대화의 모든 문맥·검토 보고서가 들어 있는 것은 아니다.
