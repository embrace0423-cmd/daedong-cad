# 대동 CAD 1.4.1 변경내역

작성 기준: 2026-11-11. 대상은 Windows x64용 대동 CAD 1.4.1이다. 기존 1.4.1-candidate.6 V02의 수정 소스를 바탕으로 앱·창 표시·실행 파일·설치기 버전을 1.4.1로 맞추고 별도의 정식 설치 경로와 사용자 프로필을 마련했다. Electron 엔진을 새로 소스 컴파일한 제품은 아니며, 검증된 기존 런타임을 새 앱 소스와 함께 패키징한다.

이 문서는 변경내역이며 새 설치·실행 시험이나 종합검토 통과를 대신하지 않는다. 실제 배포판은 동봉된 체크섬, 검증 결과 및 해당 판본의 종합검토 접수증으로 확인한다. 이전 후보의 통과 판정을 새 설치본에 자동 승계하지 않는다.

이 문서의 제품 파일 경로는 **제품 ZIP을 푼 최상위 폴더 기준**이다. 재현성 기록은 제품 ZIP의 `build-evidence/reproducible-builds-v2.json`에 있으며 원작업의 같은 기록은 `verification/reproducible-builds-v2.json`이다. 개별 기능·외부 CAD 시험과 최종 판정은 별도 검증자료 패키지에서 확인하며 제품 ZIP만으로 모든 검증 자료가 포함됐다고 해석하지 않는다.

## 정식 포장과 기존 설치 보존

- 기본 설치 폴더는 `%LOCALAPPDATA%\Programs\DaedongCAD-Release`, 실행 파일은 그 아래 `app\DaedongCAD.exe`다. 기존 `daedong-cad` 1.4.0 설치와 분리된다.
- 기본 사용자 자료 폴더는 `%APPDATA%\DaedongCAD-Release`다. 기존 1.4.0의 복구 자료·최근 파일·설정을 자동으로 이전하거나 덮어쓰지 않는다. 기존 작업 파일은 원본을 보관한 뒤 별도 사본을 열어 확인한다.
- 현재 사용자 권한으로 설치한다. 앱을 자동 실행하거나 PC를 재부팅하지 않는다. 파일 연결과 바탕화면·시작 메뉴 바로가기를 생성하지 않는다.
- 설치기는 소유 표식이 없는 비어 있지 않은 폴더, 연결된 경로, 사용 중이거나 수정할 수 없는 제품 파일, 다른 설치 모드 및 이전 버전 덮어쓰기를 거부한다. 기존 앱을 강제로 종료하지 않는다.
- 앱·제거기·설치 표식을 함께 준비·교체하고 이전 파일을 보존한다. 제거는 제품의 고정 파일 목록과 소유 메타데이터에 한정하며 사용자 프로필·도면·알 수 없는 추가 파일은 남긴다.
- 같은 소스와 고정 런타임·도구를 사용하는 재현 빌드 절차와 입력 해시를 제공한다. 현재 설치기 근거는 `packaging/BUILD.md` 및 제품 ZIP의 `build-evidence/reproducible-builds-v2.json`이다. `smoke-build6`와 `smoke-build7-reproduced`의 payload 20개·ASAR·EXE·설치기 바이트가 일치했다. 설치기는 145,229,852바이트, SHA256 `2c441f64bc547e4c925140e85ef2218a8ca041a69e4ae3805467feab72855f9f`다. 이전 재현성 파일은 현재 설치기의 근거로 사용하지 않는다.
- 실제 재설치 시험은 동일 1.4.1 → 1.4.1에 한정된다. 1.4.0 또는 다른 이전 판본의 payload 업그레이드와 자료 자동 이전을 검증한 것은 아니다.

## 후보에서 이어받은 파일 보존 동작

- 작업 파일 구조·UTF-8·이미지·참조를 검증한 뒤 현재 도면을 교체한다. 거부된 파일 때문에 기존 도면·선택·되돌리기 기록을 먼저 지우지 않는다.
- 저장은 같은 폴더의 임시 파일 검증과 이전 파일 백업을 거친다. 현재 파일의 저장 기준이 외부에서 바뀌면 덮어쓰기를 거부한다. 저장 실패를 정식 저장 성공으로 표시하지 않는다.
- 복구한 작업은 정식 파일에 저장할 때까지 미저장 상태다. 새 도면·최근 파일·종료 과정의 취소와 저장 실패는 해당 상태를 유지한다. 닫을 때 ‘저장 안 함’을 선택해도 최신 복구 보관 성공을 확인한 뒤 닫는다.
- 손상된 복구본은 거부하고 기존 도면을 유지한다. 복구 보관본은 최근 세 세대까지 보관한다.
- 작업 파일 저장과 DXF 내보내기를 분리한다. DXF 내보내기만으로 작업 파일의 미저장 상태를 해제하지 않는다. 이름이 충돌하는 도면층·블록·선종류가 서로 섞이지 않게 구분한다.

## 용량·단위·교환 범위

이미지를 포함한 작업 파일 전체의 한도는 **64MiB, 67,108,864바이트**다. 초과 파일은 읽기·저장을 거부한다. 자동복구는 브라우저 저장 공간을 사용하므로 작업 파일 한도와 별개의 더 작은 용량 또는 환경 제약에 걸릴 수 있다. 자동 보관 실패 안내가 나오면 작업 파일을 직접 저장해야 하며, 복구 기능을 정식 파일 백업의 대용으로 사용하지 않는다.

내부 길이 기준은 mm다. 인치 입력은 확인 후 25.4배로 변환한다. 단위가 없는 DXF는 사용자가 원본을 확인하여 mm 또는 인치를 선택하며 다른 명시 단위 코드는 자동 변환하지 않는다. R12 출력은 단위를 자동 보존한다고 보장하지 않으므로 수신 프로그램에서 단위를 확인해야 한다.

DXF(R12)는 이미지 밑그림을 제외하고 치수·여러 줄 문자·해치를 선·문자 또는 지원 도형으로 변환하며, 타원을 폴리선으로 근사한다. 내보내기 경고의 변환/제외 개수를 확인하고 원래 편집 정보를 가진 `.dcad.json`을 함께 보존한다. 서명이 확인된 QCAD 3.33.1 Qt5 CLI에서 새 대표 합성 네 조합을 교환한 결과는 원작업의 `verification/external-cad-20261111/REPORT.ko.md`에 있으며 제품 ZIP의 내장 파일이 아니다. 이관된 해당 보고서는 별도 검증자료 패키지의 목록에서 같은 원본 경로를 확인한다. 이는 한 외부 CAD 버전과 해당 조합의 수치 검증이며 모든 CAD·실제 도면의 호환성이나 캔버스 시각 검사 결과가 아니다.

## 남아 있는 한계

- 배포 인증서가 없어 실행 파일과 설치기는 미서명이다. 정식 버전 표기·체크섬·재현 빌드는 코드서명을 대신하지 않는다. 보안 경고나 조직 정책을 해제·우회하지 않는다.
- 실제 PC 전원 중단, 실제 시스템 디스크 포화, 다른 PC·파일시스템·모든 CAD 호환성을 확인했다고 주장하지 않는다. 오류 주입, 시험 자식 프로세스 강제 종료, 실제 앱/설치 시험은 각각의 검증 기록에서 구분한다.
- 최종 파일 지문 검사 이후 외부 프로그램이 동시에 쓰는 비협력 경쟁을 전부 차단하지 않는다. 서로 다른 이미지가 동일한 참조를 쓰는 경우 자동 병합하지 않고 거부할 수 있다.
- 자동 캡처 오류는 대표님 지시로 **이 데스크톱에서 미해결·해결 불가로 처리하고 추가 수리와 반복 시도를 종료**했다. 기술적으로 영구 불가능함을 입증하거나 해결에 성공했다는 뜻은 아니다. 부모 대화가 AI 관제의 상태 등록 완료를 확인했다고 전달했으며 이 작업에서 중복 발송하지 않는다. 이 오류를 릴리스 완료 조건으로 삼지 않고 실제 접근성 관찰·지원 입력·파일 결과의 검증 범위를 명시한다.

정식 설치·사용·제거와 실패 후 보존 방법은 제품 ZIP의 `docs/USER-GUIDE.ko.md`, 빌드 세부 사항은 `packaging/BUILD.md`, 자동 캡처 종료 상태는 `docs/CAPTURE-DISPOSITION.md`를 참고한다.
