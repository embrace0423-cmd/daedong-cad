# 대동 CAD 1.4.2 · 미터 표기 DXF 열기

DXF에 단위가 미터(m)로 표시되면 실제 도면 단위를 선택하세요.

- **mm로 읽기 (좌표 유지)**는 실제 좌표가 이미 mm인 경우입니다. 1,000으로 기록된 길이는 1,000 mm입니다.
- **m → mm 변환 (×1,000)**은 실제 미터 도면을 읽을 때 사용합니다. 1로 기록된 길이는 1,000 mm가 됩니다.
- 단위가 확실하지 않으면 **취소**하고 원래 프로그램에서 확인하세요.

Windows x64 설치기입니다. mm·인치·단위 미상 처리와 도면 파일 형식은 이전과 같습니다.
